ChatGuard Privacy Policy

Kebijakan Privasi ChatGuard

Terakhir diperbarui: 15 November 2026

"Aman dulu sebelum buka—deteksi file berbahaya secara pintar sebelum diunduh."
Privasi Anda adalah prioritas utama kami. ChatGuard dirancang untuk bekerja 100% secara lokal di perangkat Anda dalam mendeteksi file berisiko (phishing, APK palsu, PDF berbahaya).

1. Data yang TIDAK Kami Kumpulkan

  • ChatGuard tidak mengakses daftar kontak, foto/galeri pribadi, mikrofon, kamera, atau lokasi Anda.
  • ChatGuard tidak menyimpan, mencatat, atau mengirim isi percakapan/pesan chat Anda ke server mana pun.
  • Isi dokumen/file yang Anda periksa tidak pernah diunggah ke server.

2. Penggunaan Izin Perangkat

  • Akses Notifikasi & Layar Chat (opsional): Digunakan hanya di memori perangkat untuk mendeteksi pola nama file berbahaya sebelum Anda mengunduhnya.
  • Overlay (Tampil di Atas Aplikasi Lain): Digunakan untuk menampilkan kartu peringatan instan saat file berisiko terdeteksi.
  • Pemilih Folder (SAF): Digunakan hanya untuk memindai folder unduhan yang Anda pilih sendiri.

3. Mode Hybrid & Laporan Sukarela (Opsional)

Jika Anda mengaktifkan pemeriksaan reputasi server atau menekan tombol kirim laporan secara manual setelah persetujuan eksplisit, hanya metadata anonim (hash SHA-256 file, tipe file, nama paket APK, hash sertifikat, dan status penilaian) yang dikirimkan—tanpa data pribadi atau isi file.

4. Penyimpanan Lokal

Log aktivitas ancaman dan daftar blokir file disimpan secara lokal di perangkat Anda dan dapat dihapus kapan saja melalui tombol Bersihkan di Beranda aplikasi.

5. Kontak

Jika Anda memiliki pertanyaan mengenai kebijakan privasi ini, silakan hubungi pengembang ChatGuard melalui halaman repositori atau email dukungan resmi yang tercantum di Google Play Store.
